    실제 센서와 연결하기

    프로젝트의 Spring Boot 서버를 실행한 후 아래 주소를 여세요.

    http://localhost:8081

    휴대폰에서는 PC와 같은 네트워크에 연결하고
    http://PC의-IP주소:8081로 접속하세요.

    온라인 체험판은 데모 전용입니다. 실제 센서와 실험 기록은 PC에서 실행한 대시보드를 통해 사용합니다.

    실험 시작·종료는 센서 수집 자체를 켜거나 끄지 않습니다. 데이터의 비교 범위를 기록합니다. 완료 판정 임계값은 실험용이며 실기기 검증이 필요합니다.
